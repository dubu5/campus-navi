# 📍 목포대학교 공과대학 4호관 길찾기

신입생들을 위한 제4공학관 3층 길찾기 웹 안내 서비스입니다.

## 개요

- **목적**: 'ㄴ'자 형태 건물 구조로 길을 잃는 신입생을 위한 정적 웹 길찾기 서비스
- **대상**: 목포대학교 제4공학관 신입생
- **특징**: GPS/AR 없이 순수 HTML/CSS/JavaScript로 구성 (오프라인 사용 가능)

## 주요 기능

### 2단계 UX 흐름
1. **입구 선택**: 현재 위치한 1층 입구 선택 (정면/왼쪽/오른쪽)
2. **목적지 선택**: 찾는 3층 강의실 선택 (305/310/312/313호)
3. **경로 안내**: 단계별 명확한 방향 지시로 목적지 도달

### 특징
- 모바일 우선 반응형 디자인
- 다크모드 기본 적용
- 12가지 경로 조합 (3개 입구 × 4개 목적지)
- 분기점별 간단한 텍스트 안내

## 건물 구조

```
[왼쪽 복도]
  위: 308 309 310 311 312
  아래: 307 306 305 304
  [중앙 계단]
[오른쪽 복도]
  313 314 ... 323
```
