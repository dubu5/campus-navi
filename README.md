# 📍 목포대학교 공과대학 4호관 길찾기 데모

## 프로젝트 개요

대학 HCI 수업 프로젝트로, **신입생이 건물 내부 구조를 파악하지 못할 때 분기점에서 방향을 판단할 수 있도록 돕는 정적 웹 서비스**입니다.

## 배경 및 문제

- **대상 사용자**: 건물 내부 구조가 낯선 신입생
- **문제점**: 건물 안 분기점에서 방향을 판단하지 못해 감으로 진입하고 시행착오를 겪음
- **해결책**: 실제 건물 구조를 반영한 단계별 길찾기 안내 제공

## 주요 기능

### 1단계: 시작 화면 (입구 및 목적지 선택)

- **위치 선택**: "현재 위치한 1층 입구를 선택하세요"
  - 정면 입구 (실제 사진)
  - 왼쪽 입구 (실제 사진)
  - 오른쪽 입구 (실제 사진)

- **목적지 선택**: 입구 선택 후 "찾으시는 3층 강의실을 선택하세요"
  - 305호, 310호, 312호, 313호 중 선택
  - 305호, 310호, 312호는 왼쪽 복도에 배치
  - 313호는 오른쪽 복도에 배치
  - 목적지 선택 시 바로 안내 화면으로 이동

### 2단계: 안내 결과 화면 (분절적 경로 안내)

- 선택한 1층 입구와 3층 목적지에 맞춰 **헷갈리는 핵심 분기점의 행동만 카드로 순서대로 표시**
- 각 카드에는 방향 화살표(⬆️⬇️⬅️➡️)와 상세 텍스트 포함
- 'ㄴ'자 건물 구조를 SVG로 시각화
- ⚠️ 경고문: "이동 중에는 화면을 보지 말고, 분기점에 멈춰서 확인하세요"
- "처음으로 돌아가기" 버튼

## 건물 구조 및 경로 로직

### 건물 형태: 'ㄴ'자

```
┌──────────────┐
│ 300~312호    │
│ (왼쪽 복도)  │
└─────────────┬┘
              │ 313~323호 (오른쪽 복도)
              │
              ├──→ 중앙 계단
```

### 1층 입구 3곳

| 입구 | 위치 | 특징 |
|------|------|------|
| **정면 입구** | 'ㄴ'의 직각으로 꺾이는 중앙(코너) | 왼쪽·오른쪽 복도 교차점 |
| **왼쪽 입구** | 왼쪽 끝 | 왼쪽 복도 최 끝점 |
| **오른쪽 입구** | 오른쪽 끝 | 오른쪽 복도 최 끝점 |

### 3층 호수 배치

- **왼쪽 복도**: 300~312호 (305, 310, 312호 포함)
- **오른쪽 복도**: 313~323호 (313호 포함)

### 경로 매핑 (3 × 4 = 12가지)

#### 정면 입구에서

| 목적지 | 경로 | 핵심 분기점 |
|--------|------|-----------|
| 305/310/312호 | 중앙 계단 → 3층 → 왼쪽 복도 | 계단 나온 후 왼쪽으로 진입 |
| 313호 | 중앙 계단 → 3층 → 오른쪽 복도 | 계단 나온 후 오른쪽으로 진입 |

#### 왼쪽 입구에서

| 목적지 | 경로 | 핵심 분기점 |
|--------|------|-----------|
| 305/310/312호 | 왼쪽 계단 → 3층 → 중앙으로 → 왼쪽 복도 | 계단 나온 후 오른쪽으로 이동 |
| 313호 | 왼쪽 계단 → 3층 → 중앙으로 → 오른쪽 복도 | 중앙 코너에서 오른쪽으로 진입 |

#### 오른쪽 입구에서

| 목적지 | 경로 | 핵심 분기점 |
|--------|------|-----------|
| 305/310/312호 | 오른쪽 계단 → 3층 → 중앙으로 → 왼쪽 복도 | 계단 나온 후 왼쪽으로 이동, 중앙 코너에서 왼쪽 진입 |
| 313호 | 오른쪽 계단 → 3층 → 왼쪽으로 → 오른쪽 복도 | 계단 나온 후 왼쪽으로 이동 |

## 기술 스택

- **HTML5**: 마크업
- **CSS3**: 모바일 우선 반응형 디자인, 다크 모드
- **Vanilla JavaScript**: 화면 전환, 경로 렌더링, 상태 관리
- **SVG**: 'ㄴ'자 건물 구조 시각화

│   └── 오른쪽입구.jpg       # 세로 복도 끝 입구 사진

## 실행 방법

### 로컬에서 실행

1. 프로젝트 폴더를 웹 서버로 실행
   ```bash
   # Python 3
   python -m http.server 8000
   
   # 또는 Node.js (http-server 설치 필요)
   npx http-server
   ```

2. 브라우저에서 열기
   ```
   http://localhost:8000
   ```

### GitHub Pages 배포

1. GitHub 저장소 생성
2. 프로젝트 파일 푸시
3. 저장소 Settings → Pages → Deploy from branch → main 선택
4. 배포된 URL에서 접속 가능

## 설계 원칙

### UI/UX

- **모바일 우선**: 스마트폰 화면 비율 우선 설계
- **고대비 다크 모드**: 실내 밝은 환경에서도 가독성 유지
- **한국어**: 신입생 대상으로 한국어 UI 제공
- **단순함**: 정보 과부하 방지, 핵심만 표시

### 방향 표기

- **화살표 기호**: ⬆️⬇️⬅️➡️ (색상에만 의존하지 않음)
- **텍스트 설명**: "위쪽", "아래쪽", "왼쪽", "오른쪽"
- **명확한 문장**: 사용자가 즉시 이해할 수 있는 표현

### 데이터 분리

- `data.js`: 모든 경로 로직과 건물 정보를 객체로 관리
- 유지보수 용이: 경로 추가/수정 시 HTML/CSS 변경 없음
- 확장성: 다른 건물로 확대 가능한 구조

## 제외 범위 (구현하지 않은 기능)

- GPS, 블루투스 등 실시간 위치 연동
- 카메라, AR, 턴바이턴 실시간 내비게이션
- 외부의 전체 건물 평면도 이미지
- 서버, DB, 로그인, 외부 API 연동
